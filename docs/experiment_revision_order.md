## 各步骤详情

### 1. 1.7 — 确保FL训练收敛

**审稿人意见**：VGG11 + FedAvg 在 CIFAR-10 上 100 轮仅 62%-68%，远低于典型收敛水平，1.89% 的准确率差异可能只是暂态噪声。

**具体操作**：
- [ ] 增加 FL 训练轮次至模型收敛（预估需要 200-500 轮）
- [ ] 审查并统一学习率设置
- [ ] 审查并统一 batch size 设置
- [ ] 确认聚合规则（FedAvg）配置正确
- [ ] 确认客户端采样策略
- [ ] 在确保收敛的前提下重新测量 T=10 和 T=20 的准确率差异

**产出**：更新图 8 准确率曲线

**具体操作**：
