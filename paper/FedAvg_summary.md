# FedAvg 论文核心内容与实验参数总结

**论文标题**: On the Convergence of FedAvg on Non-IID Data

**发表**: ICLR 2020

**作者**: Xiang Li, Kaixuan Huang, Wenhao Yang, Shusen Wang, Zhihua Zhang (Peking University & Stevens Institute of Technology)

**arXiv**: 1907.02189v4

---

## 一、研究背景与问题

### 联邦学习的三个独特挑战

1. **通信效率低**：训练数据分布在海量设备上，中心服务器与设备间连接缓慢
2. **部分设备参与（Straggler问题）**：设备可能离线或不可用（手机关机、WiFi断开等），无法要求所有设备始终在线
3. **数据非独立同分布（Non-IID）**：各设备本地数据不能视为从总体分布中抽样，不同设备数据分布不同（`D_k ≠ D_l`）

### 已有工作的不足

- 大量已有理论分析依赖两个不切实际的假设：
  1. 数据是IID的
  2. 所有设备都参与训练
- FedProx (Sahu et al., 2018) 虽然不要求这两个假设，但其收敛理论要求近端项始终存在，无法覆盖FedAvg（FedAvg是FedProx的近端项趋零特例）
- Khaled et al. (2019) 用固定学习率分析，仅收敛到距最优解 `O(η²E²)` 的邻域

---

## 二、核心贡献

### 理论贡献

1. **首次在不假设IID数据和全设备参与的前提下，为FedAvg建立了收敛速率**：对于强凸光滑问题，达到 `O(1/T)` 收敛速率
2. **揭示了通信效率与收敛速率的权衡关系**：局部步数 E 是控制收敛速率的旋钮，E 过小或过大都不利于收敛
3. **证明了学习率衰减的必要性**（Theorem 4）：E > 1 时，即使使用全梯度下降，固定学习率也会收敛到次优点，误差为 `Ω((E-1)η)`
4. **分析了部分设备参与下的不同采样与平均策略**（Table 1），提出了新的分析框架

## 三、算法描述

### 问题建模

分布式优化目标：

$$\min_w F(w) = \sum_{k=1}^{N} p_k F_k(w)$$

其中 N 为设备数，`p_k` 为第 k 个设备的权重（`p_k ≥ 0`, `Σ p_k = 1`）。第 k 个设备的本地目标：

$$F_k(w) = \frac{1}{n_k} \sum_{j=1}^{n_k} \ell(w; x_{k,j})$$

### FedAvg 算法流程（第 t 轮）

1. **广播**：中心服务器将最新全局模型 `w_t` 广播给所有设备
2. **本地更新**：每个设备 k 设定 `w_t^k = w_t`，执行 E 步本地SGD：

   $$w_{t+i+1}^k \leftarrow w_{t+i}^k - \eta_{t+i} \nabla F_k(w_{t+i}^k, \xi_{t+i}^k), \quad i = 0, 1, \dots, E-1$$

3. **聚合**：服务器收集本地模型 `{w_{t+E}^1, ..., w_{t+E}^N}` 生成新的全局模型 `w_{t+E}`

### 采样与平均方案

| 方案 | 采样方式 | 平均方式 | 收敛速率 |
|------|---------|---------|---------|
| **原始方案** (McMahan et al., 2017) | `S_t ~ U(N, K)` | `Σ_{k∉S_t} p_k w_t + Σ_{k∈S_t} p_k w_t^k` | 无理论保证 |
| **Scheme I** (Sahu et al., 2018 提出) | `S_t ~ W(N, K, p)` 有放回按概率采样 | `(1/K) Σ_{k∈S_t} w_t^k` | `O(1/T)` |
| **Scheme II** (本文) | `S_t ~ U(N, K)` 无放回均匀采样 | `(N/K) Σ_{k∈S_t} p_k w_t^k` | `O(1/T)`* |

> *Scheme II 需要数据平衡假设 `n_1 = n_2 = ... = n_N`，但可通过尺度变换（Transformed Scheme II）解除

## 四、核心理论结果

### 假设条件

| 假设 | 内容 |
|------|------|
| **Assumption 1** (L-光滑) | `F_k(v) ≤ F_k(w) + (v-w)^T ∇F_k(w) + (L/2)‖v-w‖²` |
| **Assumption 2** (μ-强凸) | `F_k(v) ≥ F_k(w) + (v-w)^T ∇F_k(w) + (μ/2)‖v-w‖²` |
| **Assumption 3** (有界梯度方差) | `E‖∇F_k(w_t^k, ξ_t^k) - ∇F_k(w_t^k)‖² ≤ σ_k²` |
| **Assumption 4** (有界梯度范数) | `E‖∇F_k(w_t^k, ξ_t^k)‖² ≤ G²` |
| **Assumption 5** (Scheme I) | K 个索引按概率 `p_k` 独立有放回采样 |
| **Assumption 6** (Scheme II) | K 个索引从 [N] 均匀无放回采样，需 `p_1=...=p_N=1/N` |

### Non-IID 程度量化

定义 `Γ = F* - Σ_{k=1}^N p_k F_k*`，其中 `F*` 和 `F_k*` 分别为全局和局部目标的最小值。若数据IID，`Γ → 0`；若Non-IID，`Γ ≠ 0`。

---

### Theorem 1：全设备参与 (K = N)

**设定**：`κ = L/μ`, `γ = max{8κ, E}`, 学习率 `η_t = 2/(μ(γ+t))`

**收敛界**：

$$E[F(w_T)] - F^* \leq \frac{2κ}{γ+T-1} \left( \frac{B}{μ} + \frac{μγ}{2} E\|w_1 - w^*\|^2 \right)$$

其中：

$$B = \sum_{k=1}^N p_k^2 \sigma_k^2 + 6L\Gamma + 8(E-1)^2 G^2$$

---

### Theorem 2：部分设备参与 — Scheme I

**设定**：同Theorem 1，额外定义 `C = (4/K) η_t^2 E^2 G^2`

**收敛界**：

$$E[F(w_T)] - F^* \leq \frac{2(B+C)}{μ(γ+T-1)} + \frac{μγ}{2} E\|w_1 - w^*\|^2$$

---

### Theorem 3：部分设备参与 — Scheme II

**条件**：替换 Assumption 5 为 Assumption 6（数据平衡）

**C 替换为**：`C = (N-K)/(N-1) · (4/K) E^2 G^2`

**收敛界**：与 Theorem 2 相同形式

> **不平衡数据处理**：将局部目标缩放为 `F̃_k(w) = p_k N · F_k(w)`，使全局目标变为简单平均。此时用 `ν = N·max_k p_k` 替换 L，用 `ν̃ = N·min_k p_k` 替换 μ 即可。

---

### Theorem 4：学习率衰减的必要性

**构造的反例**：一个特殊的强凸光滑分布式岭回归问题

**结论**：
- E = 1 + 全批量梯度 = 全梯度下降 → 固定学习率可收敛到最优
- E > 1 + 全批量梯度 → 即使学习率任意小，FedAvg 也收敛到次优点：

$$\|w^* - w^*\| = \Omega((E-1)η) · \|w^*\|$$

---

### 关键分析洞察

#### 1. E 的最优选择

达到精度 ε 所需通信轮数 `T/E` 近似：

$$\frac{T}{E} \propto \left(1 + \frac{1}{K}\right) \left[E G^2 + \frac{\sum p_k^2 \sigma_k^2 + L\Gamma + G^2}{E} + G^2\right]$$

- `T/E` 随 E 先减后增 → **存在最优 E**
- Non-IID 下 `E = O(√T)` 不成立（与IID情况不同），E 不能超过 `Ω(T)`
- **直观解释**：E 过大时，各设备本地模型收敛到各自 `F_k` 的最小值，one-shot 平均失效

#### 2. K 的影响

- IID 下：K 增大显著提升收敛速度（线性加速）
- **Non-IID 下**：K 对收敛速率影响弱 → 可用较小的 `K/N` 缓解straggler效应

#### 3. 采样方案比较

- Scheme I：非均匀采样（按 `p_k` 概率）比均匀采样收敛更快，尤其在 `p_k` 高度不均匀时
- Scheme II：在数据不平衡时可能不稳定甚至发散
- Transformed Scheme II：稳定性好但收敛速率较低

## 五、实验设定与参数

### 模型与损失函数

| 项目 | 设定 |
|------|------|
| **模型** | 多项逻辑回归 (Multinomial Logistic Regression) |
| **预测函数** | `f(w; x_i) = softmax(Wx_i + b)` |
| **损失函数** | `F(w) = (1/n) Σ CrossEntropy(f(w; x_i), y_i) + (λ/2)‖w‖²` |
| **正则化参数 λ** | `1 × 10⁻⁴` |
| **优化问题类型** | 随机凸优化 (Stochastic Convex Optimization) |

### 数据集

| 数据集 | 设备数 N | 样本数 | 样本/设备 (mean ± std) | 说明 |
|--------|---------|--------|----------------------|------|
| **MNIST Balanced** | 100 | 54,200 | 542 ± 0 | 每设备仅含2个数字类别的样本，各设备样本数相同 |
| **MNIST Unbalanced** | 100 | 62,864 | 628 ± 800 | 每设备仅含2个数字，样本数服从幂律分布 |
| **Synthetic(0,0)** | 100 | 42,522 | 425 ± 1,372 | `α=0` 局部模型相似，`β=0` 局部数据相似 |
| **Synthetic(1,1)** | 100 | 27,348 | 273 ± 421 | `α=1` 局部模型差异大，`β=1` 局部数据差异大 |

#### 合成数据生成方法（参照 Sahu et al., 2018）

- `y = argmax(softmax(W_k x + b_k))`, `x ∈ R⁶⁰`, `W_k ∈ R^{10×60}`, `b_k ∈ R^{10}`
- `(W_k)_{i,j} ~ N(μ_k, 1)`, `μ_k ~ N(0, α)`
- `(x_k)_j ~ N(v_k, 1/j^{1.2})`, `v_k ~ N(B_k, 1)`, `B_k ~ N(0, β)`
- **α**：控制局部模型间的差异程度
- **β**：控制各设备本地数据的差异程度

#### MNIST 数据分配方式

- 数据分布到 N=100 个设备
- **Non-IID 方式**：每个设备只包含2个数字类别的样本
- **Balanced**：所有设备样本数相同
- **Unbalanced**：各设备样本数服从幂律分布

### 训练配置

| 参数 | 设定 |
|------|------|
| **初始化** | `w_0 = 0`（所有实验） |
| **学习率衰减策略** | `η_t = η_0 / (1 + t)` |
| **η₀ 候选集** | `{1, 0.1, 0.01}` |
| **每轮本地SGD步数** | E（可变） |
| **公平比较措施** | 控制所有随机性使不同算法在同一配置下激活相同设备集合 |

## 六、主要实验发现

1. **E 的最优值存在**：`T/E` 随 E 先减后增，E 过小（通信过多）或过大（收敛慢）都不好；在 MNIST Balanced 上此现象不明显，需要进一步研究
2. **K 的影响有限**：在 Non-IID 设置下，各 K 值曲线高度重叠，证明不需要激活尽可能多的设备
3. **采样方案至关重要**：
   - Scheme I 在所有数据集上表现稳定且最优
   - Scheme II 在数据平衡时与 Scheme I 几乎相同，但在不平衡时不稳定甚至发散
   - Transformed Scheme II 稳定但收敛速度较慢
   - 原始方案收敛最慢
4. **学习率衰减是必须的**：E > 1 时固定学习率收敛到次优点；衰减学习率后 E > 1 也能收敛到最优

## 七、定理与公式速查

| 定理 | 场景 | 核心公式 |
|------|------|---------|
| Theorem 1 | 全设备参与 (K=N) | `E[F(w_T)]-F* ≤ O(1/T)`, B含 `σ², Γ, E²G²` 项 |
| Theorem 2 | 部分参与 Scheme I | 在 Theorem 1 基础上增加 `C = (4/K)η²E²G²` |
| Theorem 3 | 部分参与 Scheme II | 在 Theorem 1 基础上增加 `C = ((N-K)/(N-1))·(4/K)E²G²` |
| Theorem 4 | 学习率衰减必要性 | `‖w̃* - w*‖ = Ω((E-1)η)` (固定学习率) |

### 关键常数

| 符号 | 含义 |
|------|------|
| N | 总设备数 |
| K | 每轮参与设备数 |
| T | 总SGD步数 |
| E | 两次通信间的本地迭代次数 |
| T/E | 通信轮数 |
| L, μ | 光滑性和强凸性常数 |
| σ_k² | 第k个设备的随机梯度方差界 |
| G² | 随机梯度期望范数平方上界 |
| Γ | Non-IID 程度 (`F* - Σp_kF_k*`) |
| p_k | 第k个设备的权重（通常 ∝ n_k） |
| η_t | 第t步的学习率 |
| κ | 条件数 `L/μ` |
